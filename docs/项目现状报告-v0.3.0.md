# 人生K线图 · 项目现状报告 v0.3.0（2026-11-21）

## 本版主题：通讯录与 @ 提及（所有者 2026-11-21 凌晨提出）

所有者的原话场景：先在通讯录里把人加好，写上「他是我的谁」（同学/朋友/同事/家里的谁，关系太多所以必须能自定义）；记当天事情时直接 @ 这个人（如「下午跟 @王子怡 去吃火锅」），这件事就和这个人关联起来。

与既有规则的关系：这不新增维度、不给任何人打分——人物只是故事与时间轴上的标记，正是 V0.3.3 规则 3「关系与生活事件只作时间轴标记」的落地形态。六维与评分口径未动。

## 落地内容

- 底部导航新增第六个 Tab「人物」：通讯录列表（名字 + 关系标签 + 备注 + 「X 天有关」），可搜索（人数 >4 时出现搜索框）。
- 添加/编辑联系人：名字、关系（自由文本输入 + 朋友/同事/同学/家人/亲戚/店里客人/网友快捷片，永远可以自己打字写任何关系）、备注。关系留空也可以保存，之后再补。
- 人物详情：关系与备注、与 TA 有关的天数与提及处数、全部相关日子列表（来源含故事/最好时刻/最差时刻/事件，倒序，点一条跳到那天的记录页），@名字蓝色高亮。
- 记录页故事框支持 @：输入 @ 后弹出选人条（按正在打的字过滤，显示关系），点选插入「@名字 」；通讯录里没有这个名字时，选人条提供「＋ 新建联系人」当场建人再插入（关系之后到人物页补）。
- 提及以纯文本「@名字」存进故事原文：不引入富文本，导出文件里人也能直接读。解析按通讯录现有人名最长匹配（@王子怡 不会被拆成 @王子）。已知取舍：人物改名后，旧故事里的旧名字提及不再匹配，人物详情页有明确提示。
- 时间轴的故事/事件文本同样高亮 @ 提及。
- 数据：Dexie v3 新增 people 表；导出格式仍为 lifeos-export-v1，新增可选 people 字段——无通讯录时校验和口径与 v0.2.x 完全一致（旧备份照常验得过），有通讯录时 people 纳入校验和防篡改；Markdown 可读版末尾附通讯录清单；合并/覆盖导入、清除示例、清空全部都已覆盖 people。示例数据新增两位示例联系人，其中一位被示例故事 @ 到，可直接体验完整链路后一键清除。
