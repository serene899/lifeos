- 记录：六维晨/晚/最好/最差四值（全可选）、正式事实四项、最好/最差时刻与今日故事；新增/编辑/删除/补记标记真实可用。

- 数据：IndexedDB 本地存储，刷新不丢；导出 lifeos-export-v1 JSON（含校验和）+ Markdown 可读版；
  导入校验→预览→合并/覆盖（覆盖前自动备份当前数据）；示例数据（全 synthetic 标记，可一键清除）。
