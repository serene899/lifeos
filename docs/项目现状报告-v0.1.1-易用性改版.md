# 人生K线图 · v0.1.1 易用性改版说明（2026-11-19）

触发：所有者实际打开 v0.1.0 后反馈「看了半天不会用，做得太难了」。
复盘：v0.1.0 的记录页把规格里的完整数据结构（六维 × 晨/晚/最好/最差 = 24 个选择器 + 事实 + 三个文本框）
一股脑全摊在首屏，还用了「晨·开 / 晚·收」这类规格术语。数据规则没错，但记录成本远超
本项目自己定过的验收线（每日记录 ≤90 秒、低能量时能只记一条）。是呈现层的问题，不是数据层的问题。

## 改动（只改呈现，数据结构与 V0.3.3 规则一行未动）

- 记录页默认「快速模式」：每个维度只剩一行「今晚整体」1~5 点选，六下点完；再写一句话故事，保存。
  每天的完整流程 = 点 6 个数 + 写 1 句话。
- 「记更细」折叠区：晨（早上醒来时）/ 最好（今天最好时）/ 最差（今天最差时）/ 事实四项 / 最好最差时刻，
  全部收进一个可选展开区；已有详细数据的日期打开时自动展开，不会让人以为数据丢了。
- 术语全改大白话：「晨·开」→「早上醒来时」，「晚·收」→「今晚整体」；K线页说明改为
  「记得细的日子是蜡烛，只点了今晚整体的日子是圆点，没记就空着，都正常」。
- 总览页顶部新增「怎么用？每天就三步」上手卡。
- 快速模式下 K线呈现为圆点——这正是规格规则 4 的本意：数据多细，图就多细，不伪造蜡烛。

## 验证

- tsc 0 错误；单测 28/28；e2e 3/3（新增断言：快速模式默认看不到晨/最好/最差选择器、总览有上手卡）。
- 数据兼容：DB 结构未变，v0.1.0 记的数据在 v0.1.1 原样可读。
