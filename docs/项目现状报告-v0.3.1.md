# 人生K线图 · 项目现状报告 v0.3.1（2026-11-21）

## 本版内容：R1 文案去真实人名 + R2 联系人联系方式与重要日子

所有者 2026-11-21 03:09 提出两项、并在《项目进度汇报 v0.3.0》交付后于 03:12 决定先行更新（不等 GPT 评审）。评审文档中的其余问题（Q1–Q5）仍待 GPT 回复，不在本版范围。

### R1：界面文案不再拿真实人名举例
- 加联系人名字框提示「比如：王子怡」→「比如：张三」；故事框提示「下午跟 @王子怡 去吃火锅」→「下午跟 @张三 去吃火锅」。
- 人物详情空状态里原本就按当前联系人名字动态生成（@张三），属正常功能文案非举例，保留。
- 代码注释与全部测试夹具中的同名示例一并替换（单测用「张小明/张」、e2e 用「张三」），src 与 tests 中已无真实人名。

### R2：联系人可存联系方式与重要日子（全部选填、只存本机）
- Person 新增可选字段：phone、wechat、douyin、instagram、whatsapp、email、birthday（YYYY-MM-DD）、anniversaries（多条 {名称, 日期}）、address、org（公司/学校）。Dexie 沿用可选加键，不升版本、不动旧数据。
- 编辑表单分三段：基本（名字/关系/备注）、联系方式（8 项）、重要日子（生日 + 纪念日多行增删，保存时清洗空行与坏日期）。
- 人物详情新增两块：「联系方式」（手机号为 tel: 链接可点拨打，邮箱 mailto，其余文本展示）、「重要日子」（生日与每条纪念日显示月日 + 「还有 X 天 / 就是今天」，按月日每年循环；2 月 29 日平年按 3 月 1 日算）。
- 人物列表：生日在 30 天内的联系人显示「🎂 X 天后生日」标记。
- 隐私口径：联系方式只存本机，**绝不进 lifeos-exchange 交换文件**（交换协议本就不含人物，天然隔离）；会进本 App 自己的备份导出（JSON 与 Markdown 均含），编辑页与导出说明已提示留意。
- 提醒边界：本 App 无后台推送，生日/纪念日只在打开时显示临近天数，界面已如实注明；未做 .ics 日历导出（待 GPT 评审 Q2 定夺）。

### 附带修复
