# 人生K线图 · 项目现状报告 v0.2.0（2026-11-19）

## 本版主题：数据汇入 + 自动打分（所有者拍板的产品模型修正）

所有者实际使用后明确了产品模型：人生K线图的核心功能只有两个——
① 接收钱在哪、生息、阅迹三个 App 的内容，汇成 K线图；② 手动记录补漏。
并进一步拍板（2026-11-19 10:56）：**能自动的自动打分**（健康、财务、学习、精神生活四维由汇入事实出分），
工作、情绪无数据来源由他偶尔手点；**手动分可覆盖自动分，以手动为准**。
此决定覆盖 V0.3.3 / 交换协议中「事实不产生评分」的旧口径，仅限本 App 内部呈现；
三个来源 App 的导出仍然只送事实、不送分，本版未改任何来源 App 的导出口径（阅迹为新增导出，同样只送事实）。

## 落地内容

- 「数据」页新增置顶的「收数据」区：选择 lifeos-exchange 文件 → 预览（来源/条数/天数/范围/跳过数）→ 收下。
  解析器支持三方全部现有指标：sleepMinutes、studyMinutes、spendAmount（正式事实）、
  x-income-amount、x-asset-snapshot-amount（仅 CNY）、x-exercise-minutes、x-meal-logged、
  x-reading-minutes、x-culture-activity（参考值）、感受层 sleepQuality/bodyState/energy/fatigue。
  op=void 在文件内抵消；未知指标跳过并计数，不静默吞。
- 汇入层 AutoDay 独立存储（Dexie v2 新增 autoDays 表），与手动记录分开；可整层清除，手动数据不受影响。
- 自动分引擎（autoscore.ts）：每个分带人话依据，界面标注「自动分 · 试行」。
  试行锚点：健康=睡眠时长分档（≥8h 5 分 … <5h 1 分），有睡眠质量自评时与时长分取中；
  财务=当日总资产（CNY 快照）较昨日涨跌幅分档（≥+1% 5 分 … ≤-1% 1 分），只有支出不出分（支出多≠财务差）；
  学习=学习/阅读时长分档（≥90 分钟 5 分 …）；精神=文化活动（读完看完 5 分 / 写了感受或摘句 4 分 / 只有记录 3 分）。
  工作、情绪永不出自动分。手动分存在时自动分不出现。
- 呈现：K线日K上自动分画橙色菱形（区别于手动蓝圆点），列表写明分数与依据；
  总览今日卡显示「已自动收到今天的数据」与事实摘要，六维状态在无手动时回退显示最近自动分及依据；
  记录页对有汇入数据的日期显示事实提示行。周/月聚合不并自动分（口径只认手动 OHLC）。
- 配套：阅迹 v0.2.0 新增 LIFEOS 交换导出（「我的」页 → 发到人生K线图），
  只送阅读分钟与文化活动事实，感受/摘句原文不进文件，有单测锁定。
  生息、钱在哪的既有导出入口经核查可用，本版未改动。
