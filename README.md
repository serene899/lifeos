# 人生K线图（LIFEOS 核心）

记录真实人生，而不是评判人生。

LIFEOS 的核心项目：把每天的真实经历——六个维度的主观状态、四个正式事实、
最好与最差时刻的故事、人生时间轴上的事件——记录下来，生成可回看的人生K线。
K线只是展示，故事才是本体：点开任何一天，先看到的是当时写下的话。

- 线上地址：https://serene899.github.io/lifeos/
- 规格：V0.3.3 终审规格，合规说明见 `docs/SPEC-V0.3.3-合规说明.md`
- 导出格式：`lifeos-export-v1`（JSON 完整恢复 + Markdown 人类可读）

## 功能

- **总览**：今日记录入口、最近 7 天记录情况、六维各自最近状态（不合成总分）、本月覆盖、上次导出提醒、最近故事与事件。
- **日常记录**：按日期记录六维的晨（开）/晚（收）/最好（高）/最差（低）四值（均可留空），
  正式事实四项（睡眠/学习/工作分钟、支出），最好/最差时刻与今日故事原文。支持补记（自动标记）、编辑、删除。
- **人生K线**：按维度看日K（近 30 天）/周K（近 12 周）/月K（近 6 月）。
  四值齐全才画蜡烛，部分数据只画点，缺失留空；周/月如实标注记录覆盖。
- **时间轴**：事件（只作标记，不评分）与每日故事按时间排列，事件可增删改。
- **数据**：历史列表、JSON/Markdown 导出、导入（校验→预览→合并/覆盖，覆盖前自动备份当前数据）、示例数据、清空。

## 数据与隐私

- 全部数据只存本机浏览器 IndexedDB（库名 `lifeos-kline`），无服务器、无账号、无上传。
- 已请求浏览器持久化存储，但 Safari 仍可能清除网站数据——请每月导出一次备份，存到自己掌控的位置。
- 恢复链路经过实测：导出 → 清空 → 导入 → 条数与抽样内容一致（见单测）。

## 开发

```bash
npm install
npm run dev        # http://127.0.0.1:5301
npm test           # 单元测试
npm run build      # 类型检查 + 构建到 dist/
npm run test:e2e   # Playwright（自带 Chromium，iPhone 13 视口，子路径 /lifeos/）
```

技术栈：React + TypeScript + Vite + Dexie（IndexedDB）+ Tailwind，PWA（可添加到 iPhone 主屏幕离线使用）。
K线图为自研 SVG 渲染——需要严格区分蜡烛/点/留空三态，通用图表库的蜡烛图无法表达这套规则。
